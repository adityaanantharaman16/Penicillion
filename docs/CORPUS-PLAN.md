# More variety and fairer answer coverage

Proposed editorial and engineering work, 12 November 2026. The first deliverable is a reviewed candidate release and a comparison against the current bank. The [editorial guide](../content/README.md) describes the existing build and publication process.

## Start with the gaps players encounter

The current release contains 88 prompts, 1,565 prompt–concept pairs, 1,417 distinct concepts and 2,052 additional spellings. Daily has 72 prompts (15 openers and 57 follow-ups). Its simulated minimum repeat distance is nine issues. Practice takes seven from 16 open prompts, preferring the player's least recently seen. Even with perfect ordering, three Practice runs need 21 slots. Slide Relay draws from that same pool, filters for at least eight concepts, and avoids the last seven eligible categories when possible. Rematch clears its history. Open categories currently have 15–37 answers each. Cells, pathology and physiology have zero open prompts. ## Accept more valid medical answers

1. **Define the scope before collecting terms.** Write the prompt, population or anatomy covered, level of specificity and exclusions in plain language. For a bounded set, enumerate it against a named source. For a broad set, ask two people to play it independently, then reconcile their valid responses against the bank. Narrow prompts whose boundaries reviewers cannot consistently explain.
2. **Build a reviewed concept list.** Use the pinned NLM MeSH relationships as candidates. Supplement gaps with authoritative specialty references whose usage terms are recorded. Verify each concept fits this exact prompt. Give it a stable ID, source, reason, short original fact and a prompt-specific tier. Start with common, obvious answers, then add specialist depth. Retain one attainable top-tier answer per prompt. Have a medically knowledgeable reviewer adjudicate disputed inclusions and record the review.
3. **Separate missing concepts from missing names.** For the existing surgery prompt, “surgical knife” and “scalpel” should score once, including in Relay. Record equivalent plurals, UK/US spellings, common abbreviations and eponyms when appropriate for that scope. Flag ambiguous abbreviations for clarification. Keep laterality, drug combinations, organism, type and anatomy qualifiers when they change the meaning. An example negative is “radial vein” for an artery prompt. The current solo matcher can offer a unique, conservative typo suggestion that requires confirmation. Relay should award only an accepted, unused concept. [Matcher](../server/solo/match.mjs)
4. **Learn from misses.** Start with the existing private recap report queue. Add a future Relay report action using the question and release at the moment of the miss so the fuse can keep running. Deduplicate by prompt version and normalized term. Triage weekly, first by number of independent reporters and then by medical ambiguity. Record one disposition per case: missing synonym, missing concept, ambiguous, outside scope or evidence needed. Keep reporter identity and free text restricted to reviewers. Track aggregate counts and use synthetic or de-identified examples in Git. A popular submission is a review signal.
5. **Publish repeatably.** Edit the family source and alias/fact files under [editorial](../content/editorial/), compile a candidate, validate it and stage it in an isolated database. Verify the points and source on the reveal and the duplicate-concept rule in Relay. Publish under a new content digest and refill unissued dates. Prior outcomes, in-progress runs and issued calendars retain their pinned release. Corrections may take longer to reach Daily because 35 future days are initially seeded. ## How to know the release helped

Before editing, have an independent reviewer assemble a held-out set of at least 200 in-scope player phrasings and 100 plausible invalid or ambiguous submissions across topics. Include common answers absent today, spellings, eponyms, acronyms and easy-to-confuse pairs. Label by prompt, expected canonical concept or expected rejection. Measure the current edition first. Target at least 98% acceptance of reviewed valid forms and zero false accepts on the protected negative set. Report counts and failures per mode and topic. A passing sample measures coverage on that sample only.

Test all six score levels, equivalent aliases, exclusions, ambiguous terms, duplicate passes, score stability and previous-release replay. Also check whether observed reports fall per 1,000 submissions once the new version has enough use. Keep editorial rarity fixed within a release. Document the decision on every held-out miss, coverage by family, and the 366-day simulation in the candidate review. First ticket for the next agent: baseline the measurements and prepare the 16 new open categories locally.
