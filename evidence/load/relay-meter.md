# Relay life-meter regression

The final balance ran on two local workers for 90 seconds after ramp, with 1,500 solo players and 500 connected seats across 100 five-player rooms. The generator recorded 12,644 successful writes, a peak of 176 writes/s and zero unexpected failures in 12,737 HTTP responses and WebSocket commands. Solo submissions took 16.8 ms p95 on the server. New passes reached other players on established connections in 11 ms p95 across 4,340 observations. All 500 reconnecting players received a personalized room snapshot in 42.8 ms p95, measured from each dial. The local service used PostgreSQL 17.11, Redis 7.4.12 and the restricted `night_play` role. [Measurements](measured-2026-11-12T20-10-02-187Z.json) · [Environment](environment-2026-11-12T20-10-02-187Z.json).

Two additional test players opened a separate room. One let the fuse expire naturally, dropping from three lives to two. That player's next five passes added 24, 19, 19, 19 and 19 charge. The fifth pass restored the third life with zero charge remaining. The other player's snapshot and an identical command retry showed the same event. [Live bonus trace](relay-meter-bonus.json).

An independent replay of all 2,755 durable events reconstructed every ending charge and life count for the 502 seats. It checked all six award levels on 1,692 passes, both ends of each handoff, the bonus life and 458 pops. The SQL audit found zero duplicate pops and zero lost accepted solo outcomes. [Ledger replay](relay-meter-audit-2026-11-12T20-10-02-187Z.json).

The balance tests also reached exactly 100 with five Specialist finds plus one Classic and one Clever, and with four Specialist finds plus four Student finds. Tests covered excess charge, the full-health cap, misses, duplicates, stale epochs, terminal pops, rematches, old 0/1/2-token saves and receipts, and a repeated migration. The recovery test killed a worker immediately after its handoff committed, then checked the same event and charge on the peer worker and after Redis reconnected. [Room regression](../../tests/rooms.test.mjs) · [Crash and recovery](../../tests/recovery.test.mjs).

An earlier 90-second smoke used the initial 20-charge Specialist value. It had zero unexpected failures and the ending meters of all 500 seats matched their event history. The final run above used 19. The previous 30-minute capacity baseline predates the new meter. [Earlier measurements](measured-2026-11-12T20-06-35-441Z.json) · [Earlier ledger replay](relay-meter-audit-2026-11-12T20-06-35-441Z.json) · [30-minute capacity baseline](CAPACITY.md).

To repeat the short run locally, start `LOAD_SOLO=1500 LOAD_ROOMS=100 LOAD_SECONDS=90 LOAD_PORT=4360 npm run load`. During the run, execute `LOAD_PORT=4360 node scripts/load/bonus.mjs` to exercise a real recovery. When the run ends, pass its measured JSON path to `node scripts/load/relay-meter.mjs` to reconcile the isolated database.
